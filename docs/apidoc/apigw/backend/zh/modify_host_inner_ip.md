### 描述

修改静态寻址主机的内网 IPv4/IPv6。危险接口，默认关闭，需要管理员在 `common.yaml` 或 `extra.yaml` 中开启
`hostServer.enableModifyHostInnerIP`。

权限：主机编辑权限 + 全局配置管理权限。

使用限制：

1. 主机必须是静态寻址（`bk_addressing = static`）。
2. 一次只能修改一台主机。
3. `src_*` 用于确认主机当前值，必须与当前 IP 列表**内容一致**，顺序不要求一致。
4. `dest_*` 按传入顺序写入，第一个 IP 作为主 IP。
5. IPv6 支持缩写，服务端统一转换为全格式后落库。
6. 存量 IPv4/IPv6 非法时返回 `1110072`，需要先修复数据。

### 输入参数

| 参数名称      | 参数类型  | 必选 | 描述 |
|-----------|-------|----|------|
| bk_host_id | int   | 是  | 主机 ID |
| src_ipv4  | array | 否  | 当前 IPv4 列表，与 `dest_ipv4` 成对出现 |
| src_ipv6  | array | 否  | 当前 IPv6 列表，与 `dest_ipv6` 成对出现 |
| dest_ipv4 | array | 否  | 目标 IPv4 列表，按传入顺序写入 |
| dest_ipv6 | array | 否  | 目标 IPv6 列表，按传入顺序写入 |

#### src/dest 规则

- 字段省略或为 `null`：该 family 不修改。
- 同一个 family 的 `src` 和 `dest` 必须同时提供，或同时省略；只提供一个返回 `1199010`。
- `dest` 为空数组 `[]`：表示清空该 family，但必须同时传匹配当前值的 `src`。
- `src` 为空数组 `[]`：表示确认主机当前没有该 family 的 IP，此时 `dest` 必须同时提供。
- 四个 IP 字段全部省略或为 `null`：返回 `1199010`。

### 调用示例

```json
{
    "bk_host_id": 111,
    "src_ipv4": ["127.0.0.1"],
    "src_ipv6": ["::1"],
    "dest_ipv4": ["192.168.11.1"],
    "dest_ipv6": ["2001:db8:85a3::8a2e:370:7334"]
}
```

### 响应示例

```json
{
    "result": true,
    "code": 0,
    "message": "success",
    "permission": null,
    "data": null
}
```

### 响应参数说明

| 参数名称       | 参数类型   | 描述                         |
|------------|--------|----------------------------|
| result     | bool   | 请求成功与否。true:请求成功；false请求失败 |
| code       | int    | 错误编码。 0表示success，>0表示失败错误  |
| message    | string | 请求失败返回的错误信息                |
| permission | object | 权限信息                       |
| data       | object | 请求返回的数据                    |

### 常见错误

| 错误码     | 说明 |
|---------|----|
| `1110068` | 修改主机内网 IP 功能未开启，请联系管理员 |
| `1110008` | 主机不存在 |
| `1110070` | 主机不是静态寻址 |
| `1110071` | `src` 与主机当前值不一致 |
| `1110072` | 主机当前存储的 IPv4/IPv6 值非法 |
| `1199010` | `src` / `dest` 未成对，或四个 IP 字段全部为空 |
| `1199014` | 目的 IP 已被同管控区域（`bk_cloud_id`）下的其它主机占用，返回重复的字段名 |
| `1199070` | IP 格式非法 |
| `1199047` / `1199048` | 权限相关错误 |
